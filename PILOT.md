# ILO pilot kit

How to try ILO with a small group of kids and learn something useful from it. It follows the research report's advice (PLAN.md, Phase 10): watch real kids, keep "they liked it", "they could use it" and "they learned it" apart, and test understanding on a **new** case, not only on the game they just won.

This is a guide for small, careful rounds (for example 5 to 8 kids at a time). It is not a study that can prove ILO *causes* learning. That needs a comparison group and expert help (see the end).

## Before the session

### Decide three things

| Question | Write your answer |
|---|---|
| Who? (age or grade, how well they read, school or club) | |
| Where and on what? (computers or tablets, browser, screen size, mouse or touchpad) | |
| What should they learn? (start with the gravity lesson's objective in its Teacher notes) | |

### Permission

- Get written permission from a parent or guardian, following the school's or organization's own rules.
- Ask each kid too, in simple words: "We're testing a game, not you. You can stop any time and nothing bad happens." Respect a "no", even halfway through.
- Write down **no names** on the sheets. Use a code (K1, K2, ...).
- Do not record faces or voices unless your permission form says so.

## During the session (about 30 minutes per kid)

Say as little as possible. Don't explain the map or the physics. If a kid is stuck for more than a minute, give the **smallest** help and write it down.

### Part A: before playing (3 minutes, on paper)

Show a drawing of a drone dropping a box. Ask: "On a planet with **weaker** gravity, will the box land closer, farther, or in the same place?" Circle one answer, and ask "why?" Write their words.

### Part B: the journey (20 minutes)

Tick each step and note any help given.

| # | Step | Did it alone | Needed help (what?) | Notes |
|---|---|---|---|---|
| 1 | Finds where to go (drone post, then the machine) | | | |
| 2 | Says in their own words what the mission is | | | |
| 3 | Answers the warm-ups and makes a prediction before building (note which warm-ups were right first) | | | |
| 4 | Runs the program | | | |
| 5 | Changes **one** thing and runs again | | | |
| 6 | Uses the grey mark from the last run to compare | | | |
| 7 | Uses a hint (which one: 1, 2, 3 or 4?) | | | |
| 8 | Wins the main mission | | | |
| 9 | Tries the changed case | | | |
| 10 | Wins the changed case | | | |
| 11 | Spends coins in the shop | | | |
| 12 | Goes back to the world and finds the way | | | |
| 13 | After you reload the page, finds their progress | | | |

Write down anything surprising, in the kid's words.

### Part C: right after (5 minutes)

1. "Why did the package land where it did?" (write their words)
2. New case on paper: "A drone drops a box from **2 m** instead of 8 m, on Earth. Closer or farther? Why?"
3. "What did you like? What was confusing? Would you play again?"

## One week later (5 minutes, if you can)

Ask the Part C question 2 again with a different picture (for example a ball rolling off a table on the Moon and on Earth). This checks whether the idea stayed.

## Scoring guide for the "why" answers

| Score | What the answer shows | Example |
|---|---|---|
| 0 | No idea, or only the name of the answer | "Because Mars." |
| 1 | The right direction, no reason | "Weaker gravity goes farther." |
| 2 | The reason: time in the air | "It falls slower, so it has more time to keep going forward." |

If two people score, both score the same 5 answers first and compare, so they agree on what each score means.

## After the session

- Put the sheets together without names.
- For each step in Part B: how many kids did it alone?
- Compare Part A and Part C scores.
- Note the biggest 3 problems (where most kids got stuck or confused) and send them to whoever builds ILO, with the exact words kids used.
- Do not report coins, stamps or "minutes played" as proof of learning. A kid can win by trying every option.

## What this pilot cannot tell you

- Whether ILO teaches better than a plain simulation, a worksheet or a teacher. That needs a comparison: two similar groups, same time and same idea, one with ILO and one without, planned with someone who knows how to run studies in schools.
- Whether it works for other ages, other schools or other devices than the ones you tried.
